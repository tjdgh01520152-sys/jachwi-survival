# 자취생 생존기

남은 식비로 며칠 동안 몇 끼를 해결할 수 있을지 알려주는 예산 기반 식사 생존 플래너입니다.
안암/고려대 근처를 중심으로, Kakao Local API에서 가져온 실제 식당 + 내부 요리 데이터 + 편의점을
섞어서 3가지 생존 플랜을 추천합니다.

## 왜 만들었나

자취를 하다 보면 "이번 달 식비로 며칠을 버틸 수 있을까"라는 질문에 답을 주는 서비스가 없었습니다.
맛집 추천 앱은 많지만, "예산 제약이 있는 상태에서 여러 끼니를 어떻게 배분해야 굶지 않고 버틸 수 있는지"를
계산해주는 곳은 없어서 직접 만들었습니다.

## 실행 방법

```bash
npm install
cp .env.example .env.local   # 이미 생성되어 있다면 생략
# .env.local 에 카카오 REST API 키를 채워주세요
npm run dev
```

`http://localhost:3000` 접속 후 "안암역 / 40,000원 / 8끼" 처럼 입력하고
"생존 플랜 보기"를 누르면 됩니다.

### Kakao REST API 키 발급

1. https://developers.kakao.com 에서 애플리케이션 생성
2. 내 애플리케이션 > 앱 키 > REST API 키 복사
3. `.env.local`의 `KAKAO_REST_API_KEY`에 붙여넣기

키가 없어도 화면은 깨지지 않습니다. 안암역 주변 예시 데이터로 자동 대체되고,
화면 상단에 안내 배너가 표시됩니다.

## 기술 스택

- Next.js 14 (App Router) + React + TypeScript
- Tailwind CSS
- Kakao Local API (키워드/카테고리 검색) — 서버 API route(`/api/restaurants`)에서만 호출, 키는 프론트엔드에 노출되지 않음
- 룰 기반 추천 알고리즘 (서버 호출 없이 클라이언트에서 재계산 — 카드 피드백/제외/다시 추천이 즉시 반영됨)
- localStorage 기반 개인화 (로그인/DB 없음)

## 핵심 흐름

1. 위치 → Kakao 키워드/주소 검색으로 좌표 변환
2. 좌표 기준 반경 1,200m 내 음식점(FD6)·편의점(CS2) 거리순 조회
3. 카테고리/상호명 키워드로 가격대 추정 (실제 메뉴가는 제공되지 않음)
4. 내부 요리 데이터(카레, 김치볶음밥 등)를 후보에 합류
5. 예산 적합도·취향 일치도·거리 점수·든든함·다양성 점수 - 패널티로 각 끼니 후보 점수화
6. 최대 절약 / 균형 / 가까운 곳 위주, 3가지 플랜 생성
7. 카드 피드백("너무 멀어요", "비싸요", "안 끌려요", "이곳 제외하기")이 localStorage 개인화 상태에
   반영되고, 다음 추천부터 자동으로 가중치에 반영됨
